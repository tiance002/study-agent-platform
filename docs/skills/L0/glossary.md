# L0 · 术语速查（常驻）

> 完整词汇表：`docs/superpowers/specs/2026-09-17-glossary.md`
> 本文件只收**容易混用**的高频术语，不是全量词表。缺词先查完整词汇表，仍缺再澄清。
> version: 1 | expiry: 2027-03-01

## 四根互不相干的轴（最常被混用）

| 轴 | 取值 | 含义 | **不表示** |
|---|---|---|---|
| L | L0 / L1 / L2 | 谁生成结果：确定性程序 / 本地小模型 / 云端模型 | 不表示授权，也不表示质量高低 |
| A | A0 / A1a-d / A2 / A3 | 允许做什么：不调工具 / 各类只读 / 可撤销写入 / 不可逆 | 不表示模型能力 |
| D | D0–D3 | 教学影响度：仅展示 / 影响当前建议 / 改变长期路径 / 影响证书或对外记录 | 不表示工具权限 |
| OBS | OBS-1..OBS-5 | 证据的观测强度：平台能观测到多少 | 不得与上面三轴混用 |

**铁律：轴之间通过策略表映射，不取数值最大值。**

## 数据状态类

| 术语 | 一句话定义 | 最容易误解的地方 |
|---|---|---|
| EvidenceEvent | 描述发生过什么的 append-only 事件 | 它不是日志缓存，也不是掌握状态 |
| EvidenceCorrection | 对某个证据×能力组件贡献的追加裁决 | 它不删除也不改写原始事件 |
| MasteryProjection | 从证据与裁决重建的掌握读模型 | 它不是事实源，API 不得直接写 |
| Taint | 数据来自不可信或受限来源的传播标记 | 不等于「内容一定恶意」 |
| Endorsement | 面向特定 sink/schema/主体/操作的有时限使用授权 | 它不会把原值永久变干净 |
| Reservation | 对预算的暂时冻结 | 不等于最终费用 |

## 执行与授权类

| 术语 | 一句话定义 | 最容易误解的地方 |
|---|---|---|
| Grant | 持久化的授权范围与策略结果 | 不等于短期 Token |
| Capability Token | 绑定主体、run、node、工具与过期时间的短期凭证 | 不等于租户权限总表 |
| ActionIntent | 副作用执行前持久化的意图记录 | 不是日志，是幂等与对账的依据 |
| Project Evidence | 产品运行成功/失败产生的工程证据 | 不自动证明用户掌握 |
| Learning Evidence | 专用 assessment 产生的掌握证据 | 不等于产品运行 trace |

## 2026-09-18 新增

| 术语 | 一句话定义 |
|---|---|
| ChildRun | 由父 run 派生的子任务执行单元；**不是新的授权主体** |
| 回传信封 | 子 agent 返回父对话的结构化结果，必带 artifact 引用与 `content_hash` |
| intent_tag | 工具唯一的「动词+宾语」标签，用于重叠检测 |
| sink_class | 工具结果的去向：`context` / `artifact` / `external` |
| skill manifest | `docs/skills/manifest.yaml`，设计知识的唯一索引入口 |
| 生成区 / 手写区 | 契约文档的双区结构：机器导出的部分不许手写 |
