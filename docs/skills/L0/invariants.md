# L0 · 不变量（常驻）

> 权威定义：`docs/superpowers/specs/2026-09-17-00-system-invariants-and-threat-model.md`
> 本文件是压缩摘要，供每次开工常驻加载。**与权威文本冲突时以权威文本为准。**
> version: 1 | expiry: 2027-03-01

## 一句话总纲

证据是事实，策略是关卡，token 只减不增，污点只增不减，缓存丢了不算事，失败不许静默。

## 十四条

| # | 不变量 | 违反后果 |
|---|---|---|
| 1 | 未通过身份、租户、项目校验的请求不得读取项目数据 | 跨租户泄露 |
| 2 | 查询缺少租户/项目上下文必须失败，不得回落为无过滤查询 | 越权读取 |
| 3 | 未通过 Policy Gateway 的工具调用不得进入 `dispatched` | 未授权副作用 |
| 4 | capability token 只能衰减；扩权须结束当前授权域重新签发 | 权限漂移 |
| 5 | 未注册或未标注的 node、工具、数据、副作用默认拒绝 | 未知能力入网 |
| 6 | 所有外部副作用必须先持久化 action intent | 重复副作用 |
| 7 | Redis、队列指针、缓存全部丢失不得造成事实丢失或重复副作用 | 状态不一致 |
| 8 | 预算预留失败不得执行；状态未知的调用不得盲目重派 | 成本失控 |
| 9 | 外部内容只能作为数据，不得改变策略、工具权限或预算 | 提示注入 |
| 10 | Taint 默认只增；去污点只能生成时限受控的 sink-specific endorsement；**模型摘要不能自动去污点** | 污点洗白 |
| 11 | 用户数据默认敏感，不进入非必要日志、trace、影子链路或跨项目缓存 | 隐私泄露 |
| 12 | 云端失败不得静默降级为本地高质量生成 | 质量欺骗 |
| 13 | 规则、策略、node、工具、验证器、数据集、提示词、模型，以及 **skill 与契约文档**的版本必须进入决策记录 | 无法归因 |
| 14 | 产品运行成功不能自动转化为掌握结论；掌握必须引用独立学习证据 | 错误教学判断 |

## 2026-09-18 增补（待并入 00 号规格）

| # | 增补 | 违反后果 |
|---|---|---|
| 15 | 子 agent 的 capability token 必须从父 run 派生且只能衰减，默认只持 A0/A1 | 权限旁路 |
| 16 | 子 agent 回传必须是结构化信封，携带 artifact 引用与 `content_hash`；散文摘要不得作为证据 | 谱系断裂、污点洗白 |
| 17 | skill 与契约文档只改变「模型知道什么」，不得改变「模型被允许做什么」 | 知识越界成权限 |

## 记忆钩子

- 最常被忽略的三条：**#7**（缓存不是事实）、**#10**（摘要不能去污点）、**#13**（改了文档就要改版本）。
- 判断任何设计的第一问：**它属于知识还是权限？** 权限走 registry 与 Policy Gateway；只有知识才归 skill。
- 第二问：**失败时往哪边倒？** 特权路径一律 fail-closed，不允许"暂时放行"。
