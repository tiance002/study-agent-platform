# 系统不变量与威胁模型

## 1. 信任边界

以下内容默认不可信：用户输入、上传资料、网页、代码仓库、模型输出、MCP/skill 描述、沙箱输出和第三方工具响应。云端模型与本地模型的能力不同，但都不属于授权边界。

可信计算基由身份服务、租户上下文注入、Policy Gateway、预算账本、node/tool registry、数据库约束和沙箱 broker 构成。可信组件仍可能故障，因此每个组件必须具有显式失败模式、版本和审计记录。

## 2. 可执行不变量

1. 未通过身份、租户和项目校验的请求不得读取项目数据。
2. 任意数据库查询缺少租户/项目上下文必须失败，不能回落为无过滤查询。
3. 未通过 Policy Gateway 的工具调用不得进入 `dispatched`。
4. 当前 capability token 只能衰减；扩权必须结束当前授权域并签发新 token。
5. 未注册或未标注的 node、工具、数据和副作用默认拒绝。
6. 所有外部副作用必须先持久化 action intent。
7. Redis/Valkey、队列指针或缓存全部丢失不得造成事实状态丢失或重复副作用。
8. 预算预留失败不得执行；状态未知的调用不得盲目重派。
9. 外部内容只能作为数据，不能改变系统策略、工具权限或预算。
10. Taint 默认只增加；一份值可同时带多个 `TaintSource`。获取方式不等于内容来源，派生谱系也不得塞入来源字段。去污点只能生成面向特定 sink、schema、主体和操作的有时限 endorsement，并留下 policy decision 和审计记录；模型产生新内容时必须显式增加 `MODEL_OUTPUT` 并继承全部父来源，不能自动去污点；确定性派生不得误标为模型输出。
11. 用户数据默认敏感，不进入非必要日志、trace、影子链路或跨项目缓存。
12. 云端失败不得静默降级为本地高质量生成。
13. 规则、策略、node、工具、验证器、数据集、提示词和模型配置版本必须进入决策记录。
14. 产品运行成功不能自动转化为掌握结论；掌握度必须引用独立学习证据。
15. 子 agent（ChildRun）的 capability token 必须从父 run 派生且只能衰减，默认只持 A0/A1；子 agent 不得持有 A2/A3，不得递归 spawn，深度上限为 1。
16. 子 agent 回传必须是结构化信封，携带 artifact 引用与 `content_hash`；散文摘要不得作为证据，且不得清除 taint。
17. skill 与契约文档只改变「模型知道什么」，不得改变「模型被允许做什么」；权限判断只读 registry 与策略快照。

这些不变量必须对应自动化测试或运行时断言，不能仅作为文档约定。

## 3. 主要威胁

| 威胁 | 控制 |
|---|---|
| 跨租户/项目数据泄露 | RLS、独立应用角色、事务内 `SET LOCAL`、对象与缓存双重租户校验 |
| 提示注入导致工具越权 | 数据/指令分离、最小 capability、参数级策略、受控出网 |
| SSRF、解压炸弹和依赖外传 | 独立 Fetcher/Package Proxy、私网 IP 拦截、固定 IP 连接、大小/文件数限制、沙箱解压 |
| 成本攻击 | 输入上限、每租户/用户预算、模型和工具加权限流、熔断 |
| Agent 无限循环或预算分裂 | 注册 node、树形原子预留、循环/递归/并发/工具调用上限 |
| 重试造成重复副作用 | durable intent、稳定幂等键、状态查询、对账与补偿 |
| 工作节点攻入控制面 | 独立网络、短期 token、无数据库凭据、一次性文件系统 |
| 供应链风险 | 固定版本、lockfile、哈希/镜像校验、MCP 和 skill 逐项审计 |
| 审计被篡改 | 独立 sink、应用无删除权、分级对象锁和外部锚定 |
| 错误掌握判断造成错误路径 | 多证据、影响度 D 轴、复测、申诉、可回滚投影 |
| 子任务越权或谱系断裂 | 权限从父 run 派生且只减不增；回传强制结构化信封；审计与投影旁路于上下文 |
| 文档型知识越界成权限 | skill 与契约文档不参与权限判断；registry 与策略快照为唯一依据 |

## 4. 失败模式矩阵

| 组件失败 | A0 | A1 | A2/A3 |
|---|---|---|---|
| 身份/RLS 上下文 | 拒绝项目化回答 | 拒绝 | 拒绝 |
| Policy Gateway | 已有公开上下文可回答 | 拒绝新读取 | 拒绝 |
| 预算账本 | 免费确定性操作可继续 | 昂贵操作排队 | 拒绝 |
| 检索 | 证据充分才受限回答 | 不执行新检索 | 不执行 |
| 验证器 | 低影响内容标未验证 | 仅返回原始只读结果 | 拒绝 |
| 审计 sink | 只读低风险可缓冲 | 按配置缓冲或拒绝 | 高影响操作拒绝 |
| KMS/密钥服务 | 公共内容可继续 | 无有效 DEK 则拒绝读取；新写入拒绝 | 拒绝 |
| Fetcher/Package Proxy | 无网络则停用摄取 | 只允许固定白名单 | 拒绝 |
| 云端模型 | 排队/暂停/显式失败 | 同左 | 不改变权限结果 |

缓冲审计必须有容量上限、完整性保护和恢复后回放；超过上限时 fail-closed。

## 5. 版本与治理

每次运行固定 `policy_version`、`node_registry_version`、`tool_registry_version`、`validator_version`、`dataset_version`、`prompt_version` 和模型标识。变更经过测试、canary、指标门和回滚。高风险策略禁止在运行中无版本热改。

## 6. 安全发布约束

首版默认只允许 A0 和经过拆分的 A1：项目内读取、敏感读取、外部网络读取和消耗型读取分别授权。A2/A3 必须等待 capability 扩权协议、参数确认 UI、幂等/对账适配器和专项测试全部完成后逐工具开放。Evidence 规格中的观测强度使用 `OBS-1..OBS-5`，不得与 A 权限轴、D 影响度或 L 模型档位混用。
