# 跨规格词汇表

| 术语 | 正定义 | 禁止混用 |
|---|---|---|
| EvidenceEvent | 描述发生过的学习/产品观察的 append-only 事件 | 不是日志缓存，不是掌握状态 |
| EvidenceCorrection | 对某个证据×能力组件贡献的追加裁决 | 不删除或改写原始事件 |
| MasteryProjection | 从证据和裁决重建的掌握读模型 | 不是事实源，不由 API 直接写 |
| MasteryPresentedEvent | 记录系统向用户发出了什么掌握视图 | 不表示用户一定看到了，也不是掌握事实 |
| Grant | 持久化的授权范围和策略结果 | 不等于短期 Token |
| Capability Token | 绑定主体、run、node、工具和过期时间的短期凭证 | 不等于租户权限总表 |
| Taint | 数据来自不可信或受限来源的传播标签 | 不等于“内容一定恶意” |
| Endorsement | 面向特定 sink/schema/主体/操作的有时限使用授权 | 不会把原值永久变干净 |
| Reservation | 对预算的暂时冻结 | 不等于最终费用 |
| Budget Account | 预算归属、分配和结算的账本账户 | 不等于 Redis 余额 |
| OBS-1..OBS-5 | Evidence 的观测强度 | 不得与 A 权限、D 影响、L 模型档位混用 |
| A0-A3 | 工具/副作用权限轴 | 不表示模型质量 |
| D0-D3 | 学习与决策影响度 | 不表示工具权限 |
| L0-L2 | 程序、本地模型、云端模型能力档位 | 不表示授权 |
| Source | 租户拥有并由 ACL 控制的原始资料 | 不等于 Project Index |
| PlatformContentRelease | 平台公共内容的不可变发布版本 | 不等于用户私有资料 |
| Assessment | 事前声明并冻结契约的掌握测量任务 | 不等于普通练习 |
| Project Evidence | 产品运行成功/失败产生的工程证据 | 不自动证明用户掌握 |
| Learning Evidence | 专用 assessment 产生的掌握证据 | 不等于产品运行 trace |
